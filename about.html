About College Notice Hub

College Notice Hub is a centralized platform that helps students easily find and stay updated with all college notices — examination schedules, internal assessments, placement drives, events, circulars, holidays, and general announcements — all in one place.

Instead of checking multiple notice boards or scattered messages, students can simply visit this website to search, filter, and view the latest notices published by the college administration.

This project was built as a mini-project using Python Flask, SQLite, HTML, CSS, JavaScript and Bootstrap 5.
